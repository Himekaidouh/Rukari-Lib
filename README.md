# Rukari Lib

AzureArchive（AA）模组的公共库与统一工具箱。本仓库提供 Rukari Lib、更多的画面效果、人物配音支持，以及相关源码、开发文档和示例。

**本批为面向 AA 1.0 fix6 的首次正式发布。** 安装和使用模组，请先看[用户指南](docs/users/安装与使用.md)；版本变更、源码来源和验收范围见[首次正式发布记录](docs/14_首次正式发布.md)。

| 项目 | 版本 | 作用 |
| --- | --- | --- |
| Rukari Lib | 0.4.2 | 两个功能模组共用的工具箱、设置入口和编辑服务；安装一次即可 |
| 更多的画面效果 | 1.4.1 | 调整立绘、镜头、屏幕文字和连续对白；提供摇晃、转身、头槌、弹性拉伸及贝塞尔缓动 |
| 人物配音支持 | 1.6.4 | 导入自己的音频并绑定台词，等待配音播完，可设置全局音量与结束后的额外等待 |

两个功能模组都需要 **Rukari Lib 0.4.2**，可按需要安装一个或两个。更新功能模组时请同时更新 Lib；本批新增的列表导航与发布作用域接口由该版本提供。

发布附件为三个独立 ZIP，每份仅含一个模组的运行目录与安装说明。更多 Spine 动画支持 1.6.1 的源码、测试与开发说明保留在仓库，首发附件不包含它。

## 验证范围

正式源码来自已安装的 fix6 稳定实现。用户已反馈配音播放、立绘重播正常，并在本轮确认配音窗口关闭重开保留页码、名称搜索定位正常。四套托管检查的稳定基线为 **678 项**：Core 423、Lib 149、Voice 80、Spine 26；完整构建、四个示例及依赖检查的发布结果见[构建与验证](docs/05_构建与验证.md)及[发布记录](docs/14_首次正式发布.md)。

这些确认有明确范围：中文输入法的全部情况、手动发布语音伴随目录、不同场景的性能与各类 Spine 资产没有因此获得全面验收。助手没有启动或控制游戏；构建工具的 `Native=not-run` 标记保持原义。其它 AA 版本需单独适配和验证。

## 开发和构建

源码放在 `src` 下，保留现有项目引用关系。先阅读[构建文档](docs/05_构建与验证.md)。仅托管测试无需游戏；完整游戏适配构建需要开发者自己的 AA 1.0 fix6 与 BepInEx/interop 文件。

运行 PowerShell 7：

    pwsh -File src/build.ps1 -CoreOnly
    pwsh -File src/build.ps1 -GameRoot '你的 AA 1.0 fix6 目录'

构建脚本不会安装模组或启动游戏。默认构建目标为 Release10；`-Target Preview10` 保留旧基线的构建入口。回执记录实际游戏文件哈希，目标名称不能代替兼容验证。其它 AA 版本需重新验证。

完整构建通过后，生成本次三个独立用户 ZIP：

    pwsh -File src/scripts/New-UserPackages.ps1 -OutputDirectory '新的用户包输出目录' -ReleaseChannel Stable -UserAcceptancePath '你的用户验收记录文件'

脚本默认生成 Candidate 候选包；正式包需显式指定 `-ReleaseChannel Stable` 和本次用户验收记录。验收记录及其证据引用用于打包核验，保留在用户 ZIP 外。

每份 ZIP 仅包含一个模组的 `mods` 目录和 `安装说明.txt`。Lib 独立提供共享依赖与 UI 素材，功能包不重复携带。构建与打包审查记录保留在 ZIP 外，用户无需安装这些记录。

原有 `src/scripts/New-ModPackages.ps1 -OutputDirectory '新的输出目录' -Zip` 保留为四模组候选包入口。两个入口都要求输出目录不存在或为空，并核对构建来源、依赖和素材；均不安装模组或启动游戏。

src/examples 提供共享语音、工具页、插件入口和自定义指令的示例。新增功能应使用 Lib 服务与注册接口，避免复制公共 UI 宿主或修改既有公共接口签名。

## 发布范围与许可

用户安装编译后的模组包；开发者使用本仓库源码。用户包只提供运行所需文件、图标、许可和安装说明，不包含用户工程、用户音频、个人配置、日志、构建记录或官方程序集。发布源码排除暂停的原生指令迁移实验、半成品字幕插件与实验性 Spine 叠加台；共享库内的既有模型和接口仍保留。

自有代码采用 [MIT](LICENSE)。随 Lib 提供的一份共享 UI 素材不属于 MIT 授权，详见 [素材说明](src/assets/rukari-lib/ui/NOTICE.md)。

`provenance` 保留初始来源与历史审查记录；当前正式源码来源及元数据升版见[首次正式发布记录](docs/14_首次正式发布.md)。历史安装版本和哈希仍用于追溯，不能代替本批发布文件的校验记录。
