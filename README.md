# Rukari Lib

AzureArchive 模组的公共库与统一 UI 宿主。本仓库同时提供基于它开发的功能模组源码、完整构建依赖源码和示例。

| 项目 | 版本 | 作用 |
| --- | --- | --- |
| Rukari Lib | 0.4.1 | 统一工具箱、模组设置、编辑器服务、指令扩展接口和共享运行服务 |
| 更多的画面效果 | 1.4.0 | 人物位置、旋转、翻转、镜头、连续对白与预设动作；预设支持贝塞尔曲线 |
| 人物配音支持 | 1.6.2 | 从用户音频文件夹为台词配音，播放等待与全局结束延迟 |
| 更多 Spine 动画支持 | 1.6.1 | 动画选择与切换、记忆大厅播放适配 |

## 开发和构建

源码放在 src 下，保留现有项目引用关系。先阅读构建文档。仅托管测试无需游戏；完整游戏适配构建需要开发者自己的 AA 与 BepInEx/interop 文件。

运行 PowerShell 7：

    pwsh -File src/build.ps1 -CoreOnly
    pwsh -File src/build.ps1 -GameRoot '你的 AA 目录'

构建脚本不会安装模组或启动游戏。当前适配构建目标是 Preview10，对应本次 AAfix 4 验证基线；其它 AA 版本需重新验证。

src/examples 提供共享语音、工具页、插件入口和自定义指令的示例。新增功能应使用 Lib 服务与注册接口，避免复制公共 UI 宿主或修改既有公共接口签名。

## 发布范围与许可

用户安装编译后的模组包；开发者使用本仓库源码。未包含半成品字幕插件、实验性 Spine 叠加台、官方程序集、用户工程、音频或本地诊断数据。共享库内的模型和接口仍保留，以保持完整 API。
