# Rukari Lib

AzureArchive（AA）模组的公共库与统一工具箱。本仓库提供 Rukari Lib、更多的画面效果、人物配音支持，以及相关源码、开发文档和示例。

**安装和使用模组，请先看[用户指南](docs/users/安装与使用.md)。** 本次用户包面向 AA 1.0，仍是测试包，尚未发布稳定版。

| 项目 | 版本 | 作用 |
| --- | --- | --- |
| Rukari Lib | 0.4.1 | 两个功能模组共用的工具箱和设置入口；安装一次即可 |
| 更多的画面效果 | 1.4.0 | 调整立绘、镜头、屏幕文字和连续对白；提供摇晃、转身、头槌、弹性拉伸及贝塞尔缓动 |
| 人物配音支持 | 1.6.2 | 导入自己的音频并绑定台词，等待配音播完，可设置结束后的额外等待 |

两个功能模组都需要 Rukari Lib，可按需要安装其中一个或两个。本次分别打包这三个模组；更多 Spine 动画支持 1.6.1 的源码与开发说明仍保留在仓库，本次用户包不包含它。

## 开发和构建

源码放在 src 下，保留现有项目引用关系。先阅读构建文档。仅托管测试无需游戏；完整游戏适配构建需要开发者自己的 AA 与 BepInEx/interop 文件。

运行 PowerShell 7：

    pwsh -File src/build.ps1 -CoreOnly
    pwsh -File src/build.ps1 -GameRoot '你的 AA 目录'

构建脚本不会安装模组或启动游戏。默认构建目标为 Release10；`-Target Preview10` 保留旧基线的构建入口。回执记录实际游戏文件哈希，目标名称不能代替兼容验证。其它 AA 版本需重新验证。

完整构建通过后，生成本次三个独立用户 ZIP：

    pwsh -File src/scripts/New-UserPackages.ps1 -OutputDirectory '新的输出目录'

每份 ZIP 仅包含一个模组的 `mods` 目录和 `安装说明.txt`。Lib 独立提供共享依赖与 UI 素材，功能包不重复携带。构建与打包审查记录保留在 ZIP 外，用户无需安装这些记录。

原有 `src/scripts/New-ModPackages.ps1 -OutputDirectory '新的输出目录' -Zip` 保留为四模组候选包入口。两个入口都要求输出目录不存在或为空，并核对构建来源、依赖和素材；均不安装模组或启动游戏。

src/examples 提供共享语音、工具页、插件入口和自定义指令的示例。新增功能应使用 Lib 服务与注册接口，避免复制公共 UI 宿主或修改既有公共接口签名。

## 发布范围与许可

用户安装编译后的模组包；开发者使用本仓库源码。用户包只提供运行所需文件、图标、许可和安装说明，不包含用户工程、用户音频、个人配置、日志、构建记录或官方程序集。本仓库不包含半成品字幕插件与实验性 Spine 叠加台；共享库内的模型和接口仍保留，以保持完整 API。

自有代码采用 [MIT](LICENSE)。随 Lib 提供的一份共享 UI 素材不属于 MIT 授权，详见 [素材说明](src/assets/rukari-lib/ui/NOTICE.md)。

provenance 记录稳定基线的源码输入与哈希。初始上传业务源码与原基线一致；后续审查清理了开发机路径与测试依赖，具体差异记录在审查文档中。托管测试与编译不能代替游戏内验证。
