# Rukari Lib

AzureArchive（AA）模组的公共库与统一工具箱。本仓库提供 Rukari Lib、更多的画面效果、人物配音支持，以及它们的源码、开发文档和示例。

本批面向 **AzureArchive 1.01**。

## 下载

从 [Releases](https://github.com/Himekaidouh/Rukari-Lib/releases) 下载本批附件：

| 附件 | 模组 |
| --- | --- |
| `RukariLib-0.4.4-AA1.01.zip` | Rukari Lib（前置，必装） |
| `Rukari.MoreEffects-1.6.6-AA1.01.zip` | 更多的画面效果 |
| `Rukari.CharacterVoice-1.6.8-AA1.01.zip` | 人物配音支持 |

每个 ZIP 只含一个模组的 `mods` 目录和安装说明，不含用户工程、音频、个人配置或日志。

使用 **AA 1.0 fix6** 或 **1.0beta** 时请改用 [v2026.10.03](https://github.com/Himekaidouh/Rukari-Lib/releases/tag/v2026.10.03) 的附件，本批只针对 1.01 构建。

## 安装

1. 完全退出 AA。
2. 解压各 ZIP，把包内的 `mods` 文件夹合并到 AA 主程序所在目录。已有 `mods` 时合并即可。
3. 启动 AA，在官方“Mod 管理”中启用 RukariLib 和需要的功能模组。
4. 退出并重新启动 AA。

更新功能模组时请同时更新 Rukari Lib。详细步骤见[安装与使用](docs/users/安装与使用.md)。

## 本次更新（0.4.4 / 1.6.6 / 1.6.8）

- **整行排成一条队列**：在台词卡的额外指令里加 `#aavt;queue`，这一行的效果按书写顺序一段接一段播放；不加就是各层同时开始。
- **效果按层排**：人物、镜头、预设各成一层，层内按顺序播放，不同层同时开始；人物和镜头都提供“载入第 k 段”与“替换第 k 段”，用来原地修改一整段效果。
- **预设效果改为独立窗口**：可以和编辑器同屏，窗口位置在本次会话内记忆。
- **同一句设置人物起点与终点**：人物先定位到“初始位置 A”，再按设定时长与缓动移动到“目标位置 B”。
- **有限动作完成后自动推进**：位移、旋转、镜头动画及设定了次数或时长的预设动作接入 AA 的动画等待，多个动作并行时等最后完成的一个。
- **配音可以手动跳过**：点击对话区域或按 Enter 即可跳过配音及结束后的等待，AUTO 仍等待语音播完。
- **修复**：一行里写两条相同指令会让整个工程的效果失效；正式播放时动作只有结果、没有过程；带效果的行在编辑器里点绿色预览按钮不生效。

相对上一个发布版（Rukari Lib 0.4.2、更多的画面效果 1.4.1、人物配音支持 1.6.4）的完整列表见本批 Release 说明，逐条记录见[更新日志](docs/47_更新日志_20261014.md)。

## 从源码构建

需要 PowerShell 7、支持 net6.0 的 .NET SDK，以及自己的 AA 1.01 与 BepInEx/interop 文件。

    pwsh -File src/build.ps1 -CoreOnly
    pwsh -File src/build.ps1 -GameRoot '你的 AA 1.01 目录'

完整构建通过后生成三个用户 ZIP：

    pwsh -File src/scripts/New-UserPackages.ps1 -OutputDirectory '新的输出目录' -ReleaseChannel Stable -GameLabel AA1.01 -UserAcceptancePath '你的验收记录.json'

两个脚本都不会安装模组，也不会启动游戏。构建目标 `Release10` 的名称不能代替兼容验证，其它 AA 版本需单独核对。见[构建与验证](docs/05_构建与验证.md)与 [Stable 用户包验收绑定](docs/Stable用户包验收绑定.md)。
