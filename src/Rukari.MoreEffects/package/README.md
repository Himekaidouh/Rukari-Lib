# 更多的画面效果 1.6.5

用于 AA 1.01 的人物与镜头演出工具，需要 RukariLib 0.4.3。

## 功能

- 人物位置、X 轴前后旋转、Z 轴倾斜、翻转，以及同句初始位置 A → 目标位置 B。
- “整体”和“仅背景”两个独立镜头范围，支持移动、缩放、过渡和分别复位。
- 左右摇晃、X/Y 轴旋转、头槌、弹性拉伸等预设，可调整参数与贝塞尔缓动。
- 屏幕文字、连续对白、位移继承及有限动作等待。
- 支持读取通过一致性校验的 AAP2 官方兼容投影。

## 使用

1. 退出游戏，合并用户包的 `mods` 文件夹，在官方 Mod 管理中启用 RukariLib 和“更多的画面效果”，然后重启。
2. 打开 Script 节点并选中台词，从左侧工具箱进入“更多的画面效果”。
3. 在人物、镜头或“预设效果”页面编辑当前台词，应用后点击绿色重播预览。
4. 保存工程；正式播放前保存并发布作品。

完整用户说明见 [more-effects.txt](../../packaging/user/more-effects.txt)。
