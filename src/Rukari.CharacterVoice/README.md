# 人物配音支持 1.6.5

适用于 AA 1.0 fix6，需要安装并启用 RukariLib 0.4.2。共享工具箱和图集随 Lib 提供，本包不包含音频文件。

在工程的 Script 节点选择台词，打开「人物配音支持」，选择音频文件夹并导入，再选择声音、应用到当前句并保存工程。支持 WAV、OGG、MP3。迁移工程时携带完整工程资源；分享作品时，将 `作品名.aas` 与同名的 `作品名.rukari` 文件夹放在一起。

配音列表在同一次游戏会话中记住页码和搜索词。关闭重开、切换工具或切换台词保留位置；不同工程、已导入声音和文件夹预览分别保存浏览状态。退出游戏后不保留这份状态。

名称搜索保留完整列表，优先定位完整名称，再定位第一个包含输入文字的声音所在页。支持粘贴和回车再次定位；定位不会自动选择、导入或绑定声音。

全局选项位于 AA 设置 → 模组设置 → 人物配音支持：

- 配音音量：0–100%，默认 50% 保持原有响度，仅作用于本模组导入并绑定的声音。
- 语音结束后的额外等待：0–10 秒，默认 0 秒；音频末尾的静音也计入播放时间。

本版同步提升 Lib 依赖下限，避免旧版 Lib 缺少列表导航接口。播放签名适配与音量策略沿用 1.6.3 的实现；本次发布不代表全部原生调用都已逐项验收。具体实现、安装和验收范围见 [fix6 适配记录](../../docs/10_AA1.0_fix6适配.md)及[配音列表页码与名称定位](../../docs/13_fix6配音列表页码与搜索定位.md)。
