# 人物初始位置 A 与目标位置 B（1.5.4 候选）

空对话卡在部分正式播放路径下仍不能可靠触发指令。本次新增同句起点，不将空对话问题宣称为已修复。

## 使用

1. 在一张正常台词卡上选择已有人物的槽位，打开“更多的画面效果 → 立绘操控”。
2. 点击“初始位置 A”，拖拽红框中的人物或使用 X/Y 按钮设置起点。
3. 点击“目标位置 B”，设置终点，再设置时长与缓动。
4. 点击“应用草稿”，手动保存工程用于预览效果；正式播放前保存并发布工程。

只设置 A 时立即定位到 A。A 与 B 都有设置时，播放先立即定位到 A，再移动到 B。后续台词没有指定 A 时，继续使用原有的上一句终点继承逻辑。“取消指定起点”会保留 B；如果指令只设置了 A，取消时会提示先设置 B，或在官方额外指令框中删除该定位指令。

空槽位仍使用原有 `charPending` 入场定位；本次不把待入场定位改成延迟动画。相对位移指令可手写起点，但仍提示使用指令编辑。与官方位置过渡同槽位的冲突检查继续生效。

## 指令与坐标

```text
#aavt;char;3;set;startX=-900;startY=50;x=400;y=200;duration=600;easing=easeInOut
```

三号槽位先立即放到 A=(-900,50)，再在 600 毫秒内移动到 B=(400,200)。X/Y 使用与现有位置指令一致的槽位局部偏移，不是屏幕像素。原点与官方物理槽位一致；红框内的坐标转换保留现有规则。

```text
#aavt;char;3;set;startX=-900;startY=50;duration=0;easing=linear
#aavt;char;3;move;startX=-900;startY=50;dx=300;dy=20;duration=600;easing=easeOut
```

以上是两个独立用法示例，不能在同一台词卡上同时放两条针对三号槽位的定位指令。第一个只定位；第二个从 A 开始做相对位移，终点为 (-600,70)。

省略某个 start 轴时沿用该轴的当前位置，Z 深度及未指定旋转保持原值。非有限数、重复字段、reset 中的起点，以及 charPending 的起点均拒绝，不静默丢弃。旧指令无需修改。使用新增字段的工程需要 1.5.4 或后续支持版本，旧版会拒绝未知字段。

## 技术实现

- `CharacterTransformCommand` 以附加可选属性保存 `StartX/StartY`，保留原有构造函数。
- 解析、验证、规范化、图形草稿、官方额外指令写入与保存投影使用同一组字段。A/B 属于一条同槽位指令，不放宽每卡同槽位唯一性。
- `CharacterTransformPlanner` 先求 A，再从 A 求绝对或相对的 B；目标携带 `InitialPosition`。原始官方基准仍在应用前捕获，整体重置回到原官方基准。
- `CharacterTransformService.Apply` 在同一次执行里用现有立即定位方法放到 A，再启动既有 `TweenPosition` 到 B，继续使用已有缓动；出错仍走既有回滚路径。
- 重播恢复、预览资源占用和官方位移冲突检查包括 start 轴。预览链先折叠 A，再折叠 B，供下一句继承的是终点。
- UI 的 A/B 编辑模式只影响位置字段，保留旋转、翻转、时长；点击同一人物开始拖拽时保留正在编辑的端点，切换槽位/台词时回到 B。

## 验证边界

新增托管回归覆盖绝对 A→B、重复重播、单轴与仅起点、从 A 相对位移、旧指令与重置、无效值及 pending 拒绝、文档替换与字段往返、后续台词终点继承、预览资源删除恢复、保存投影和官方过渡冲突。构建与安装记录位于 `artifacts/character-initial-position-20261006`。

真实游戏中的 UI 拖拽、绿色重播、正式手动播放及从第一句 AUTO 仍需要分别测试 fix6 和 1.0beta。该功能不会使官方跳过的空卡自动变成可播放事件，也不解决整段空对话或 AUTO 启动的既有未验证问题。
