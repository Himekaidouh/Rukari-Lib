# 人物配音支持 1.6.8 · 手动跳过候选

配音播放时长和结束后的全局额外等待仅约束 AUTO。手动点击对话区域或按 Enter，可以沿用 AA 原有文字显示与推进操作，不再被配音模块强制要求等到播放结束。修改未添加音频副本，也未修改工程保存格式。

## 实现

- `VoicePlaybackGate.BlocksAdvance` 新增 AUTO 状态和手动输入参数，原二参数重载保留原有约定。
- 对话区域实际 `OnTouchAreaClicked` 回调释放当前配音等待；如果更早的其他 Mod 已取消原调用，不执行释放。不通过全局鼠标按下判断，点击设置、AUTO 开关等其他 UI 不构成跳过。
- 在正式 `AdvanceScenario` 入口读取官方 `Test.IsAutoEnabled`，非 AUTO 推进放行。在实际推进边界识别 Enter 与数字键盘 Enter，使 AUTO 打开时的手动输入也能跳过。
- 取消当前请求会递增其代次，取消播放和额外间隔；已有原生播放观察确认的音源按现有停止路径清理。beta 旧接口的异步缓存重试只接受当前活动代次，不会在取消后重新播放。
- 保留 fix6 原生 `SetVoice(string, onStarted)` 的开始回调，不保存、包装或替换回调对象。MoreEffects 的推进观察仍排在配音门禁之后；AUTO 被阻止时不开新窗口，手动获准时照常观察。
- 模组设置页面明确标注等待仅用于 AUTO；音量设置和官方 AUTO 等待保持现有行为。

仅核对官方 interop 声明与现有运行时接口，未读取官方方法体或反编译官方源码。

## 验证与待确认

新增五项托管测试，覆盖 Loading、Starting、Playing、PostPlaybackDelay 下的手动放行、AUTO 等待、切换 AUTO 不重启时限、取消后的旧代次及相同声音的新代次隔离。

两版需实机确认：播放中左键/Enter/数字键盘 Enter；额外等待设为 3 秒时手动跳过；保持 AUTO 时等待语音和间隔；首次未缓存配音开始加载后立即跳过；同时启用 FL 与 AAVT 时推进和效果执行正常。

特别是 fix6 冷加载属于原生异步开始管线，取消托管等待不等于证明原生迟到开始回调已经取消。当前不增加全局音源播放补丁或广泛停止共享音源；此场景的晚响和旧回调需实际日志确认。Enter 的生产输入路径也须实机验证，不能用声明和托管测试替代。
