## 一、窗口宿主（8 步）

进游戏 → 工程 → 台词编辑界面（左侧工具图标出现）。

1. **打开**：点左侧「预设效果」图标 → 应弹出**独立的浮动小窗**（默认贴左下，约 532×640 px，左边距 12、底边距 44），标题「预设效果」，右上 ×，右下角一个小方块。
   *不对时*：看 `BepInEx\LogOutput.log` 里的 `[tool-window] rukari.moreeffects.presets opened`；若完全没有这行，说明窗口没建起来（会有一条 `could not be created` 或 `was not registered`）。
2. **拖动**：按住标题带拖到屏幕中间 → 窗口跟着手走，松手停在原处（内容不应滞后一帧或跳位）。
3. **缩放**：拖右下角小方块 → 从**左下角**为锚点变大变小；拖到很小会停在最小尺寸（360×200）而不是反过来。
4. **双击复位**：快速双击标题带 → 回到默认位置**和**默认尺寸（此后窗口重新跟随页面请求的尺寸）。
   *不对时*：日志里应有 `placement reset to default`，随后一行新的 `placement=`。
5. **关闭与重开**：点 × → 窗口消失；再点图标 → 重新出现，**且位置/尺寸与关掉前一致**（本次游戏内记住；重启游戏回默认）。
6. **同屏**：点「更多的画面效果」打开抽屉（立绘操控）→ 两个界面**应能同时在屏幕上**、都能操作；窗口压在抽屉上时，点窗口不应同时触发抽屉。
7. **置顶**：把两个窗口都打开（预设 + 时间轴）拖到重叠 → 点下面那个 → 它应升到上面，并且**点击只被它接住**。
8. **离开工作台**：回工程首页或打开官方资源选择窗 → 两个界面都隐藏；回到台词编辑界面 → 按原位置、原开关状态恢复。

*日志关键字*：`[tool-window] <id> opened / closed / placement=x,y WxH / moved; placement=… / resized; placement=… / placement reset to default`。拖动期间**不应**每帧刷行。

## 二、预设页在窗口里的行为（4 步）

1. 点开某一类预设进入**详情视图** → 窗口应自动**变高**以容纳详情（在你自己拖过缩放角之前）；返回选择器 → 变回。
2. 数字输入框：点击后可输入、退格、回车提交；中文输入法输入时，候选框应出现在输入框附近。
3. 应用/撤销按钮行为与在抽屉里一致。
4. 如果**手动**把窗口拖得比页面需要的还小，页面会自己叠在一起——这是老页面按固定底栏布局的行为（`docs/03` §5.5 已记），拖大即恢复。

## 三、时间轴面板（6 步）

**先选中一句带动作的台词**，再点左侧「时间轴」图标。

1. **出现**：底部弹出一条横条窗（默认约 1212 px 宽，高度随轨道数变化）。顶部一行应显示 `工程 · 场景 n · 台词　指令 N 条 / 官方行 M`；左侧轨道名（角色 n / 预设 n / 镜头）；中间刻度尺与段块；右侧属性栏；底部状态行。
2. **对数（最重要）**：用你熟悉的测试行（例如带 `at=1500` 的那张），把状态行的 `总时长 … ms`、以及点中段块后属性栏的 `起点 1500 ms` / `时长 300 ms`，与之前跑出来的 `queue-segment-due … startMs=1500; durationMs=300` 对照——两者必须一致。
3. **选中**：点一个段块 → 属性栏显示它的轨道、第几条指令与原文行号、起点/时长/终点、类型、授权（`at=` / `interrupt=` / 未指定）；再点一次取消选中。
4. **换行**：改选另一句台词 → 面板跟着换；取消选中 → 显示「当前台词不可用，请重新选中台词。」而不是留着上一行。
5. **刷新**：点「刷新」立即重读（用于你在别处改了这条附加指令之后）。
6. **拥挤情况**：轨道多于面板高度时，底部会写「还有 N 条轨道放不下，请把窗口拉高」——把窗口拉高即可全部显示。

*日志关键字*：面板每次换行/换计划写一行 `[timeline] 工程 · 场景 n · 台词　指令 … · 总时长 … ms · 段 … · 轨道 …`；读不到时写 `Timeline source read unavailable: …`（同一原因只写一次）。**这一行让我不必看屏幕就能核对数据链路。**
