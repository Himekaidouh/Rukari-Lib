## 已实现的交互

立绘操控新增“Z 轴·平面倾斜 / X 轴·前后翻转”切换。转盘、±1°、±15°与角度归零只修改当前轴；另一轴的草稿保留。预设仍位于“预设效果”内，维持摇摆、旋转、头槌、挤压拉伸四类；旋转参数页可选 X/Y，旧工程不指定轴时仍为 Y。头槌的旧 Z 轴三阶段动作不变。

镜头页新增“整体·背景与人物 / 仅背景”。两个范围分别保留同一卡片的草稿、时长和缓动；切换范围不会把参数复制到另一个范围。每次“应用草稿”写入当前范围；应用成功后，另一范围草稿仅在能证明这是自己的同卡编辑事务时更新来源修订，否则重新核验。切卡、撤销或离开镜头模式会作废相应临时草稿。当前没有“一次应用两份草稿”或“一键全部镜头复位”；分别切换范围应用或重置即可。

背景框的拖动/缩放使用整体与背景的组合状态计算，反算只改变当前范围。立绘占位框仍是二维示意，不能用于判断 X 旋转的背面、厚度或透视效果。

## 指令与旧工程兼容

基础旋转字段新增 `rotationX`（绝对 X 角度）、`drotationX`（相对 X 角度）。旧 `rotation` / `drotation` 始终为 Z；省略 X 时保留原 X。角度限制 ±3600°，非有限数值或不适用的 set/move/reset 字段会拒绝。

三号槽位示例，写入 AA 的额外指令框或由本模组控件生成：

```text
#aavt;char;3;set;rotationX=30;rotation=-10;duration=600;easing=easeInOut
#aavt;char;3;move;drotationX=360;duration=1200;easing=linear
#aavt;char;3;reset;duration=0;easing=linear
```

以上是分别使用的示例；同一张卡同一槽位不能同时放多条同类基础变换。reset 仍按原规则回到本次场景/占用者捕获的基线姿态，并包含新增 X 通道。

旋转预设新增 `axis=x|y`，仅对 spin 有效。省略或 `axis=y` 的规范文本保持原格式；不会把旧 Y 转身改成翻跟斗。

```text
#aavt;fx;3;spin;axis=x;frequency=1;cycles=2;direction=right;bezier=0.42,0,0.58,1
```

`cycles=0` 保持循环至下一段对话的既有语义。次数与曲线限制沿用旧预设；同一卡同一槽仍只允许一种预设。

镜头新增 `scope=background`；省略范围仍为整体，规范化时不为旧整体指令追加字段。同一张卡可以同时保存一条整体与一条背景镜头：

```text
#aavt;camera;set;zoom=1.2;duration=600;easing=easeInOut
#aavt;camera;set;scope=background;zoom=1.5;duration=1000;easing=linear
```

背景复位只撤销背景范围，整体复位只撤销整体范围：

```text
#aavt;camera;reset;scope=background;duration=0;easing=linear
#aavt;camera;reset;duration=0;easing=linear
```

reset 的目标为所选范围的 `(X=0,Y=0,Zoom=1)`。指令编辑资源为整体槽 0、背景槽 6；人物仍用 1–5。每个范围每卡只保留一条镜头指令。scene 指令上限从 21 增至 22，以容纳第二个镜头资源，并保留原角色/预设/Spine 轨道预算。

## X 旋转的姿态链

解析、规范化、目标规划、暂存目标、祖先继承、未保存覆盖、预览资源 footprint 和 reset 均携带 X。原构造函数及已公开方法签名保留，新字段通过附加属性提供。

Unity 可能把同一姿态返回为另一组 Euler 数值，例如 authored `(120,0,0)` 与 observed `(60,180,180)`。新增 `CharacterEulerRepresentation` / `CharacterRotationRepresentationStore` 在确认物理方向相同后选取接近作者角度的表达，避免超过 90° 后参数反向或把旋转圈数丢掉；提示绑定播放器、人物、根对象和占用者身份。外部已改变的姿态仍以新鲜实际读数为准。

预设帧新增 pitch 通道，旧帧构造器保留。连续旋转保留未绕回轨迹，不能因整圈起终点方向相同就跳过动画。姿态方向相等只是释放自身临时修改的检查，不证明 FL 或其他 Mod 的写入归属；尚未建立跨模组同对象同属性动画合成协议。

主要代码：Core/Characters 的 TransformContracts/Planner、PresetEvaluator/PoseOverlay、RotationRepresentationStore；运行层 CharacterTransformService、CharacterPresetRuntime；编辑层 VisualCharacterDraftBuilder、VisualEditorBehaviour 和 CharacterPresetToolContent。

## 镜头组合与单写入器

设整体状态为 `(Gx,Gy,G)`、背景状态为 `(Bx,By,B)`：

- 人物层倍率为 `G`，偏移为 `(Gx×G,Gy×G)`。
- 背景层倍率为 `G×B`，偏移为 `(Gx×G+Bx×G×B,Gy×G+By×G×B)`。
- 实际写入为各层捕获的原始位置减去上述偏移，原始 XY 缩放乘上述倍率。

仍操作已验证的 `UI Root/Back` 与 `UI Root/Spine`，不改真实 Camera，不重建对象父子关系，不缩放台词和按钮。一个 `SceneCameraService` 负责两份状态和最终物理写入，两个范围动画可同时推进；不让两套 Tween 争抢 Back。只做背景动作时不写 Spine。对象重建时重取物理基线、清除旧 scene entry 和范围状态，不套用旧对象身份。

两份倍率和组合倍率都限制 0.1–8；组合位置必须有限。动画期间按范围包络保守校验，极端相反动画即使端点可用也可能拒绝。旧整体动画保留物理偏移端点插值，避免把位置与倍率各自线性插值后产生非预期弯曲。四种缓动以公开 NGUI 公式为参考；真实 AA 的 steep curve/时间尺度配置尚未取得实机一致性证明。

继承链分别折叠 0/6。权威编辑覆盖中的空值表示该范围已删除，禁止回退已保存索引而复活旧效果。继承写入失败时，清理证据只来自本次实际开始的 setter，包含另一范围仍在推进导致的实际写入；仅背景残留只登记槽 6，回滚成功不扩大清理。没有新增原生 getter/补丁目标。

主要代码：Core/Cameras 的 CompositionPlanner、Motion、MutationAttempt；Core/Commands 的 CameraChainResolver、DirectiveAuthority、LeasePlanner；运行层 SceneCameraService、PlayerCommandObservationRuntime；编辑层 VisualCameraFrameMath 和 VisualEditorBehaviour。

## Lib 页面故障与发行校验

第三方工具页的尺寸 getter、OnShown、Draw 出错时，只隔离当前注册的当前页；其余页仍可打开。错误帧中的控件、拖动、焦点和输入占用会释放，部分成功的 OnShown 仍配对一次 OnHidden。生命周期回调内部换页时按新的显示代处理，不把旧页异常转嫁给新页；关闭再打开允许一次重试，不逐帧反复调用出错页面。

Stable 用户包现在要求结构化人工验收记录绑定当前三个包版本、构建回执和六个 DLL 哈希。历史自由文本不能将本次候选版标为稳定；Candidate 默认不变。详见 [Stable 验收绑定](Stable用户包验收绑定.md)。此门只校验证据对应的产物，不能代替真实用户确认。

### 实机第一轮：三号槽位

1. 保留一个人物在槽 3，在立绘页分别调整 X=30°、Z=-10°，应用后连续绿色重播三次；确认不累积、不跳槽。再测 X=120° 与恢复为 0°，检查数值方向及画面。
2. 从“预设效果 → 旋转”先测 Y 一圈，再切 X 两圈。有限次数结束后归位；再测循环至下一句、换卡和换人物。检查已有摇摆/头槌/拉伸仍可用。
3. 镜头仅背景设置 1.5 倍，确认人物大小不变；整体设置 1.2 倍，确认人物为 1.2、背景组合为 1.8，台词、按钮和工具窗大小不变。两范围不同动画时长也测试。
4. 同卡同时调两份镜头草稿，切换后分别应用；逐个重置，确认另一范围保留。删除背景指令后切下一卡并重播，确认不从旧保存索引复活。
5. 同时启用 FL 5.2.0，用已经验证的 FL 移动示例，分别测试同卡两种指令顺序、绿色重播、正常切卡；正式播放单独检查。未知同轴叠加不作为已支持组合。
6. 打开人物、差分、声音选择窗口确认工具避让，退出返回；至少在两个窗口大小下检查 X/Y 选择和镜头范围栏的排版。
