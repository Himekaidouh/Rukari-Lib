# 2026.10.14 更新说明

| 模组 | 版本 | 需要 |
| --- | --- | --- |
| RukariLib | 0.4.4 | — |
| 更多的画面效果 | 1.6.6 | RukariLib 0.4.4 |
| 人物配音支持 | 1.6.8 | RukariLib 0.4.4 |

安装：退出游戏 → 合并 `mods` → 官方 Mod 管理里启用 → 重启。

## 新增

- `#aavt;queue`：整行按写的顺序播（人物-人物-镜头）；不加＝各层同时开始。画面编辑器里有开关。
- `载入第 k 段` / `替换第 k 段`：改一段不用删掉重加，位置不变。人物 / 镜头 / 预设都有。
- 效果按层排：镜头层在镜头模式，人物层在人物模式，预设层在预设效果窗口；独立的「镜头效果」窗口去掉了。
- 工具箱：单条目模组打开独立窗口时，工具列一起收起（RukariLib 0.4.4）。

## 修复

- 一行里写两条相同指令，会让整个工程的所有效果失效（`＋ 加为下一段` 连按两次就会触发）。
- 人物模式的层编辑器压住旧控件。
- `＋ 加为下一段` 在人物模式点不动。
- 切换镜头范围（整体 / 仅背景）后，上移或删除可能作用到另一层。
- 队列时长上限 3 秒 → 10 秒。
