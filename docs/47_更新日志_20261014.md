# 2026.10.14 更新说明

三个模组一起更新，都要求 RukariLib 0.4.4。

| 模组 | 版本 |
| --- | --- |
| RukariLib | 0.4.4 |
| 更多的画面效果 | 1.6.6 |
| 人物配音支持 | 1.6.8 |

**安装**：退出游戏 → 把各包里的 `mods` 合并进游戏目录 → 在官方 Mod 管理里启用 RukariLib 和需要的模组 → 重启游戏。工程文件不需要转换。

## 更多的画面效果 1.6.6

### 新增：整行排成一条队列

在台词卡的额外指令里加一行 `#aavt;queue`，这一行的效果就按**写的顺序**一段接一段播：

```
#aavt;queue
#aavt;char;3;set;x=-843.98;y=411.862;duration=600;easing=easeInOut
#aavt;char;3;set;x=661.68;y=20.255;rotation=-60;duration=600;easing=easeInOut
#aavt;camera;set;x=-418.614;y=303.83264;zoom=1.983;duration=600;easing=easeInOut
```

上面这一行：人物演完两段，镜头才开始。

不加这一行就是各层同时开始，和以前一样，老工程不用改。

画面编辑器里有开关：`队列：串成一条` / `队列：各层并行`，按一下即时生效，也可以手写这一行。

### 新增：效果就地改

人物、镜头、预设三处都有 `载入第 k 段` 和 `替换第 k 段`：把某一段读回编辑器改，改完写回**原来的位置**。

以前改一段只能删掉重加，那一段会跑到本层末尾，顺序就变了。

### 新增：效果按层排

- 镜头层在画面编辑器的镜头模式，人物层在人物模式，预设层在预设效果窗口。
- 层内按写的顺序播，不同层同时开始。
- 独立的「镜头效果」窗口已去掉，镜头就在画面编辑器里编。

### 改动

- 队列总时长上限 3 秒 → **10 秒**。超过上限的部分直接跳到结束状态；按队列开关时会显示这一行的总时长。

### 修复

- **一行里写两条完全相同的指令，会让整个工程的所有效果失效**（`＋ 加为下一段` 连按两次就会触发）。现在重复指令正常播两遍。
- 人物模式的层编辑器压在旧控件上。
- `＋ 加为下一段` 在人物模式点不动。
- 切换镜头范围（整体 / 仅背景）后，上移或删除可能作用到另一层。
- 预设效果窗口打开时，工具列会一起收起。

### 限制

- 相对移动段（`move`）不能载入编辑器，只能直接改指令。
- 起点预置段（人物入场起点）不参与排队。
