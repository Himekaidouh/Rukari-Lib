# Rukari 模组更新日志 · 2026-10-14

| 模组 | 上一发布版 | 本次版本 |
| --- | --- | --- |
| Rukari Lib | 0.4.3 | 0.4.4 |
| 更多的画面效果 | 1.5.5 | 1.6.6 |
| 人物配音支持 | 1.6.8 | 1.6.8 |

人物配音支持本次无功能改动，随 Rukari Lib 0.4.4 重新打包。

## 新增功能

- **整行排成一条队列**：在台词卡的额外指令里加 `#aavt;queue`，这一行的效果就按写的顺序一段接一段播（人物-人物-镜头）；不加就是各层同时开始。画面编辑器里有开关。
- **效果按层排**：镜头层在画面编辑器的镜头模式，人物层在人物模式，预设层在预设效果窗口；层内按顺序播，不同层同时开始。独立的「镜头效果」窗口已去掉。
- **效果就地修改**：人物 / 镜头 / 预设都有 `载入第 k 段` 与 `替换第 k 段`，改一段不用删掉重加，位置不变。
- **同一人物的多个动作按顺序执行**：同一句里给同一人物或镜头写多段动作，以前后面的会覆盖前面的，现在按写的顺序依次播放。
- **预设效果改为独立窗口**：可以和工具箱同屏，可拖动，位置在本次会话内记忆。
- **空台词卡也能触发效果**：只有效果、没有正文的台词卡现在会正常触发。

## 问题修复

- 一行里写两条相同的指令，会让整个工程的所有效果失效（`＋ 加为下一段` 连按两次就会触发）。
- 队列总时长上限 3 秒 → 10 秒。
- 正式播放时动作"只有结果、没有过程"（位移从 1 直接到 4，中间被跳过）。
- 带效果的行在编辑器里点绿色预览按钮不生效。
- 部分工程里扩展指令动作在播放模式不显现（`#wait` 短于动作时长、空白 script 节点、有内容的节点未被上下文连接）。
- 人物模式的层编辑器压住旧控件。
- `＋ 加为下一段` 在人物模式点不动。
- 切换镜头范围（整体 / 仅背景）后，上移或删除可能作用到另一层。
- 工具箱：打开独立窗口时，工具列一起收起。

## 更新说明

请使用 AA 1.0，优先选择最新修正版。更新功能模组时，同时更新 Rukari Lib，并在官方 Mod 管理中选择新版本、重启游戏。
