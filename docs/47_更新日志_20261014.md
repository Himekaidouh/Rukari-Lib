# 2026.10.14 更新说明

| 模组 | 版本 | 需要 |

安装：退出游戏 → 合并 `mods` → 官方 Mod 管理里启用 → 重启。

## 更多的画面效果 1.6.6

- 新增 `#aavt;queue`：整行按写的顺序播（人物-人物-镜头）；不加＝各层同时开始。画面编辑器里有开关。
- 新增 `载入第 k 段` / `替换第 k 段`：改一段不用删掉重加，位置不变。人物 / 镜头 / 预设都有。
- 效果按层排：镜头层在镜头模式，人物层在人物模式，预设层在预设效果窗口。独立的「镜头效果」窗口去掉了。
- 队列时长上限 3 秒 → 10 秒。
- 修复：一行里写两条相同指令会让整个工程失效（`＋ 加为下一段` 连按两次就会触发）。
- 修复：人物层编辑器压住旧控件；`＋ 加为下一段` 点不动；切镜头范围后可能删错层。
- 不能：相对移动段不能载入；起点预置段不排队。
