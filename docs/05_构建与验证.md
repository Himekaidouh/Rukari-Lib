# 构建与验证

## 环境

PowerShell 7、支持 net6.0 的 .NET SDK 和 .NET 6 Runtime。基线使用 SDK 7.0.403。完整适配编译需要开发者自己的 **AA 1.0 fix6**、BepInEx/core 与 BepInEx/interop。官方 DLL 不随仓库分发。

## 入口

在仓库根运行：

    pwsh -File src/build.ps1 -CoreOnly
    pwsh -File src/build.ps1 -GameRoot '你的 AA 1.0 fix6 目录'

CoreOnly 构建并运行四套纯托管测试，不加载 Unity。完整构建另外编译四个模组和四个示例，并检查四个模组的依赖；Spine 参与源码核验，但不进入首发用户附件。默认 Release，支持 -Configuration Debug 和 -SkipTests；跳过测试不得视为验证通过。

默认 `-Target Release10` 对应正式版适配；`-Target Preview10` 保留旧基线。两者沿用现有编译分支，本轮不以改名推断接口兼容性。SchemaVersion 2 构建回执记录目标目录及游戏、interop、模组加载器等输入哈希。

当前稳定功能基线为 **678 项**：Core 423、Lib 149、Voice 80、Spine 26。两个既有符号链接子夹具因平台权限跳过。实际发布构建与打包结果以[首次正式发布记录](14_首次正式发布.md)及本次回执为准；元数据升版后应重新完成统一构建、示例、依赖和包内校验。

构建工具的 `Native=not-run` 表示助手没有通过该工具执行游戏内验收。用户确认的配音、立绘重播与配音列表交互另记录在发布文档，不能把这个字段改成所有原生路径均已通过。构建生成的 artifacts 回执不提交到 Git。

构建入口不复制文件到游戏、不改 Profile、不启动或关闭游戏。跨 AA 版本必须重新编译并进行游戏内验收。两个首发功能包要求 Lib 0.4.2，应与本批共享依赖配套安装。

## 用户安装包（三个独立 ZIP）

    pwsh -File src/scripts/New-UserPackages.ps1 -OutputDirectory '新的用户包输出目录' -ReleaseChannel Stable -UserAcceptancePath '你的用户验收记录文件'

该入口生成 RukariLib 0.4.2、更多的画面效果 1.4.1、人物配音支持 1.6.4 三个独立正式 ZIP。两个功能包均依赖同批 Lib，只有 Lib 携带共享图集。输出目录仅有三个 ZIP，每个内含该模组的 `mods/模组名/版本/` 与一份简短安装说明；不附源代码、开发工具、配置、工程、音频、构建回执或 Spine 包。

脚本默认 `-ReleaseChannel Candidate`，生成候选包。正式归档需显式指定 `Stable`，并用 `-UserAcceptancePath` 提供本次用户验收记录。该记录及其证据引用参与发布核验，保留在用户 ZIP 外，不作为用户安装内容。

该脚本调用下述完整打包验证，检查当前源码、构建、fix6 输入和依赖，再从明确清单选取三个模组。生成后逐项读取 ZIP 内文件并核对哈希。构建暂存、校验记录放在 `src/artifacts/user-packages`，与用户交付目录分开。安装说明模板放在 `src/packaging/user`。精确附件清单和 SHA256 在发布归档时记入[首次正式发布记录](14_首次正式发布.md)。

## 完整四包核验（内部使用）

    pwsh -File src/scripts/New-ModPackages.ps1 -OutputDirectory '新的内部核验输出目录' -Zip

输出目录必须不存在或为空。脚本要求完整 Release10 构建与测试通过，重新核对源码清单、游戏输入、四包依赖和 UI 素材校验，再按明确清单复制 7 个 DLL、四份 manifest、图标及许可。Lib 是唯一共享库与基础 UI 素材提供者；没有官方程序集、PDB、半成品字幕或实验叠加台。用户 ZIP 只带 mods 和短说明，含本机路径的构建回执留在外部。打包不安装、不切换配置、不启动游戏。

## 来源

`provenance/original-source-files.json` 保留初始导入的原始 SHA256；它是历史来源记录，不是本批每个文件的当前哈希。正式源码以已安装的 `fix6-voice-navigation-20261003` 稳定快照为基础：433 个净源码树文件、418 项构建输入。此次发布单独升版 Lib、配音和画面效果的元数据，避免新增接口仍与旧版共用版本号。

初始整理、发布前清理、fix6 适配及后续修复的过程分别保留在第八至十三篇文档；当前发布范围集中在第十四篇。暂停的原生指令实验不进入正式源码，原工作树和备份不作为发布输入。

共享 UI 放在 src/assets/rukari-lib/ui，仅 Lib 携带。构建入口校验其哈希，素材许可见同目录 NOTICE.md。不要将游戏 DLL、自己的工程、语音、本地日志或凭据提交到 Git。
