# 项目与源码导航

本仓库以 Rukari Lib 为主体，包含更多画面效果、人物配音与 Spine 支持的稳定实现。不是旧开发目录的整体镜像。

| 目录 | 内容 |
| --- | --- |
| src/Rukari.Lib | 公共接口、纯托管服务、设置及统一 UI 模型 |
| src/Rukari.Lib.Runtime | 游戏内宿主、统一 UI 渲染与编辑器适配 |
| src/Rukari.MoreEffects | 更多画面效果插件及其替代实现 |
| src/AzureArchive.VideoTools | 被 MoreEffects 显式编入的共享历史源码；仅保留实际编译文件 |
| src/AzureArchive.VideoTools.Core | 指令、动作规划、预览身份与继承等纯托管逻辑 |
| src/AzureArchive.VideoTools.Formats | 格式读取与自己的数据结构 |
| src/Rukari.CharacterVoice | 人物配音、文件夹选择与播放等待 |
| src/Rukari.SpineSupport | Spine 与记忆大厅适配；不含实验控制台 |
| src/examples | 四个接口示例 |
| src/assets | Lib 共享 UI 与四个产品图标 |
| provenance | 原始输入、哈希与编译项目清单 |

项目清单以 provenance/project-inputs.json 为准：11 个主解决方案项目与 4 个示例项目。详细立绘实现请读第二篇文档；新增模组请读第三篇与 examples。

注意 MoreEffects 同时编译旧共享目录和新插件目录；同名文件应以 csproj 的 Include/Remove 和实际输入清单确认，不要仅凭文件名修改。
