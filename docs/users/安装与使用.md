# 安装与使用

本批为 AzureArchive（AA）**1.0 fix6 正式版模组包**。从同一批发布附件下载 Rukari Lib 和需要的功能模组。

## 选择需要的模组

| 模组 | 版本 | 用途 |
| --- | --- | --- |
| Rukari Lib | 0.4.2 | 提供统一工具箱和模组设置；下面两个模组都需要它 |
| 更多的画面效果 | 1.4.1 | 立绘摆放、旋转与翻转，镜头、屏幕文字、连续对白和预设动作 |
| 人物配音支持 | 1.6.4 | 导入自己的音频并绑定台词，设置配音音量及播放后的等待 |

先安装 Rukari Lib，再按需要安装一个或两个功能模组。更新时也请安装本批 Lib 0.4.2。本批不包含“更多 Spine 动画支持”。

## 安装

1. 完全退出 AA。
2. 解压 Rukari Lib 和所需功能模组的 ZIP，将各包内的 `mods` 文件夹合并到 AA 主程序所在目录。已有 `mods` 时合并即可；更新同名模组时覆盖包内对应文件。
3. 启动 AA，在官方“Mod 管理”中启用 **RukariLib 0.4.2** 及所需功能模组；更新后选择表中的新版本。
4. 退出并重新启动 AA。

每个 ZIP 只带一个模组的运行文件和安装说明，不带用户工程、音频、个人配置或日志。无需安装仓库源码或开发检查记录。

## 打开工具

打开工程，进入 **Script 节点的台词编辑界面**，再从侧栏工具入口打开所需功能。工具不会在工程列表或其它编辑页面一直显示；需要编辑某句时，先选中该句。

打开人物、表情、音乐或音效等选择窗口时，工具会暂时隐藏。关闭选择窗口后，可从侧栏重新打开工具。

## 更多的画面效果

在工具箱打开“更多的画面效果”，选中台词及目标人物槽位，调整立绘位置、旋转或左右翻转；也可以切换到镜头、屏幕文字等工具。完成调整后点击“应用草稿”，再播放或重播当前句查看效果，并保存工程。

“预设效果”提供四种动作：

- **左右摇晃**：人物左右倾斜，结束后恢复原姿势。
- **原地转身**：绕 Y 轴转身，结束后恢复原朝向。
- **头槌**：先后仰，再向前顶出，最后恢复。
- **弹性拉伸**：横向拉伸、纵向压扁，或反向变化，结束后恢复。

选择目标槽位和动作，调整幅度、时长等参数，点击“应用到当前句”。“缓动曲线”可选择线性、缓入、缓出、缓入缓出，或用自定义贝塞尔曲线调整动作快慢。应用前切换台词会清除尚未应用的草稿。

完成编辑后，打开“工程保存”，点击“保存并发布”更新可播放作品。

## 人物配音支持

1. 打开并保存工程，在 Script 节点选中要配音的台词。
2. 打开“人物配音支持”，点击“选择语音文件夹”。支持 WAV、OGG、MP3，默认只扫描所选目录；需要时开启“包含子目录”。
3. 确认文件列表，点击“导入此文件夹音频”，等待导入完成。
4. 在已导入声音列表中选中音频，点击“应用所选声音”，将它绑定到当前台词。
5. 播放或重播该句检查配音。可用“移除本句语音”解除绑定，或用“撤销最近编辑”撤销操作。
6. 完成编辑后保存工程，并使用 AA 的发布入口生成可播放作品。安装了“更多的画面效果”时，也可在“工程保存”中点击“保存并发布”。

关闭配音窗口再打开，会在同一次游戏会话中保留页码和搜索词。输入或粘贴声音名称并按回车，可定位到匹配条目所在页；搜索保留完整列表，定位后仍需自行选择并应用声音。工程与列表来源各自保留位置，退出游戏后浏览状态不保留。

导入会把音频复制进工程。迁移工程时，请带上完整工程资源；分享编译后的作品时，需将 `作品名.aas` 和同名的 `作品名.rukari` 文件夹一起提供，放在同一目录。发布后先在目标目录检查一次播放再分享。

播放会等待配音结束。打开“模组设置”→“人物配音支持”，可调整配音音量和语音结束后的额外等待。音量范围为 0–100%，默认 50% 保持此前响度，0% 静音；下一段配音起使用新设置。额外等待范围为 0–10 秒，默认 0 秒。音频末尾自带的静音也算播放时间，AA 的 AUTO 等待继续使用游戏设置。

## 找不到工具时

先检查官方“Mod 管理”里是否同时启用了 RukariLib 和对应功能模组，并确认启用后已重启 AA。随后打开工程的 Script 节点，关闭人物、音乐等选择窗口。按钮不可用时，重新选中要编辑的台词。
