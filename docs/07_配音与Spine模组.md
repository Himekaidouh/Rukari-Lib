# 人物配音与 Spine 支持

## 人物配音支持 1.6.4

用户选择自己的音频文件夹，扫描音频后在当前台词上绑定、移除或撤销配音。稳定实现跟随编辑器选句，不要求切换 MCP 页面或手动寻找 inbox。

播放时等待人物语音结束，再按全局设置追加延迟；默认 0 秒，范围 0–10 秒。这是所有语音共用的模组设置，不逐句写入工程。

全局音量为 0–100%，默认 50% 保持此前响度，0% 静音；修改后从下一段配音起使用新设置。列表在同一次游戏会话内按工程与来源保留页码和搜索词，名称搜索定位完整列表的匹配页，不自动选择或绑定声音。相关交互已获用户确认，详细范围见[导航修复与验收](13_fix6配音列表页码与搜索定位.md)。

工程保存与编译经现有编辑器服务、官方保存调用及相应守卫执行。配音已移除普通编译后追加的整份作品发布；更多画面效果的手动“保存并发布”使用显式资源作用域覆盖完整调用链。分享含自定义语音的作品时，应同时提供作品 .aas 和对应 .rukari 音频目录；只分享存档不会包含用户音频。本模组不会将用户音频上传到网络。

技术入口：src/Rukari.CharacterVoice/Core 是纯逻辑，Runtime 是编辑器、音频和 UI 适配；Tests 有独立纯托管验证。保存链的完成状态与限制详见第四篇文档。

## 更多 Spine 动画支持 1.6.1

提供剧情与记忆大厅动画选择、切换与播放适配，处理默认动画、伴随轨道、触摸区域及过渡策略。不是完整的自定义互动事件引擎。

本仓库保留稳定运行源码及测试，不包含实验性 Spine 叠加台的三个控制台文件，也不启用 IncludeExperimentalSpineConsole。

首次正式发布的用户附件为 Lib、配音和画面效果三个 ZIP，Spine 1.6.1 参与源码构建与测试，首发不提供它的用户安装包。

技术入口：src/Rukari.SpineSupport；纯策略测试位于 Tests。原生 Spine 对象生命周期与游戏版本相关，编译和托管测试通过不代表每份 Spine 资产均已游戏内验收。
## 旧功能清理

失效语音清理按钮及直接改写工程清单/语音索引的实现已删除。缺失资源只做诊断，不自动删除。旧清理会触发 AA 外部修改保护，不属于正常配音必需流程。
