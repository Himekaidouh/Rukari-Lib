# 2026 年 10 月 6 日更新说明

本轮用户包包含 RukariLib 0.4.3、更多的画面效果 1.5.5、人物配音支持 1.6.8。分别提供 AA 1.0 fix6 与 AA 1.0beta 的对应构建，**不包含视差及纵深实验功能**。

本轮新增功能已完成代码实现、构建和离线测试，尚待两版 AA 的游戏内验收，因此本次标为**候选版**。

## 更多的画面效果

### 同一句设置人物起点与终点

立绘操控新增“初始位置 A”“目标位置 B”和“取消指定起点”。可以在同一张台词卡里，先指定人物出现的位置，再让人物移动到终点，无需为了设置起点另加一张空台词卡。

- 只设置 A：立即把人物放到指定位置。
- 同时设置 A、B：先放到 A，再按设置的时长和缓动移动到 B。
- 不指定 A：继续继承上一句同一人物的状态；新加入或重新入场的人物使用官方默认槽位。

起点与终点都能通过拖拽或 X/Y 按钮编辑。原有旋转、翻转、缓动和位移继承继续保留。本轮也补齐了新增起点字段在指令编辑、草稿、保存和重播中的处理。

### 有限动作完成后再自动推进

人物位移、旋转、镜头动画，以及有明确次数或时长的预设动作，加入 AA 的动画等待流程。目标是让空台词里的动作也有足够时间完成，不再要求用户手工补等待指令。

- 多个动作同时运行时，等待最后完成的动作，不把各自时长累加。
- 摇摆、转圈、挤压拉伸按次数与频率计算时长，头槌按指定时长处理。
- “直到下一句”的循环效果不造成无限等待。
- 瞬间定位不额外增加动画时长；切换台词或取消播放后，不继续等待旧动作。

这部分还需要实测动画观感、从第一句开启 AUTO、手动跳过，以及与 FL 指令和配音同时使用的情况。

### 改善空台词的触发处理

补充对实际解析到的空台词的识别，以及快速切换、重复回调的处理，减少效果漏触发或重复执行的可能。

**整段 Script 节点全部为空台词的问题尚未彻底解决。** 动画等待不能替代工程与播放记录的可靠对应关系，目前不能保证这类节点在正式播放中生效。设置人物初始位置时，优先使用本轮新增的同句 A/B 功能。

## 人物配音支持

### 配音等待只约束 AUTO，手动可以跳过

播放配音时，手动点击对话区域或按 Enter 可以沿用 AA 的显示文字和推进操作，不再被配音模块强制要求等完整段语音及结束后的额外间隔。

AUTO 仍等待配音结束和用户设置的间隔，间隔默认 0 秒。点击设置窗口等其他界面不会被当成跳过对话。本轮保留全局配音音量、页码记忆和名称定位，不生成增强音频副本，也不修改原音频。

仍需实测首次加载语音时立即跳过、Enter 的实际操作，以及取消后是否有迟到的语音播放。

## 安装与验证状态

1. 先退出 AA，按实际游戏版本选择 `AA1.0-fix6` 或 `AA1.0beta` 目录。每个目录都有三个独立用户包。
2. 将需要的 ZIP 中的 `mods` 文件夹合并到同一份 AA 游戏目录。更多的画面效果和人物配音支持都需要 RukariLib 0.4.3。
3. 在 AA 设置 → Mod 管理中启用对应版本，再重启。保留原有工程、语音资源和配置。
4. 编辑效果后“应用草稿”，手动保存工程用于预览效果；正式播放前保存并发布工程。

两套构建均通过，四组离线测试合计 904 项、失败 0 项。安装包还核对了 DLL、版本、依赖和文件清单。**这些检查不能代替本轮候选功能的游戏内验收**，本次仍标为候选版。
