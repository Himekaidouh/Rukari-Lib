# AA 1.0 适配记录（2026-10-01）

## 范围与状态

适配用户最终指定的 `AzureArchive_100_1001` 版 AA 1.0，基线为同日完成侧栏遮挡修复的源码。四包为 RukariLib 0.4.1、更多的画面效果 1.4.0、人物配音支持 1.6.2、更多Spine动画支持 1.6.1。版本号与公共 API 保持兼容；本轮按正式版随包文件重编，不能用文件夹内的旧版本号推断构建来源。

当前为适配候选，Native=not-run；没有发布稳定版 Release 或标签。

## 兼容性依据

只读取随包 interop 声明、场景序列化引用及现有模组源码，没有反编译官方方法体。

- 模组加载器 ModTheAzureArchive 与 fix4 逐字节相同，SHA-256 为 `9E3F26880208F0DAF7443ABB146D69EC6C549FCA7D60141A68B4DA8BF368FAE7`；官方示例沿用 `name` / `version_number` / `dependencies: ["Name/Version"]`。
- UI 的 1,209 行相关声明一致。ScriptNodeInspector、InspectorPanel、UI Root 的面板关系，以及 WindowPanel 下各选择器的路径、活动标记和组件类型一致。WindowManager 仍指向 Blocking 与 UIPanel；人物、表情、音乐、音效等弹窗遮挡时隐藏侧栏的实现沿用。
- Mod 管理入口由官方在运行时生成。SettingPanel.modManagerEntry 及复制所需声明仍在，相关设置表格的序列化配置一致；离线检查不能保证生成后的实际排版，需要游戏内检查。
- MoreEffects 的 22 处重点调用边界与参数一致，包括编译净化、台词推进、打字机、当前节点与选择行、人物变换和保存编译入口。整体比较 24 个类型，发现的差异在当前未使用成员和编译器生成元数据中。
- 配音、Spine 及相关文件入口共比较 444 个类型、8,095 个方法和 2,586 个属性，声明、参数名及默认值元数据零差异。语音预加载状态机两边均为 `_CoTryPreloadVoice_d__104`，源码按前缀查找并检查成员类型。

构建回执保存具体目标文件哈希；最终目标的详细比较脚本和数据留在本地 `src/artifacts/aa10-final-20261001`，不随用户包分发。

## 原生验收与现有边界

编译和声明检查不能确认官方方法内部行为。本次未启动游戏，也没有修改用户工程或音频。需要在正式版检查：

1. 模组列表加载四包；设置窗口中“模组设置”入口出现且对齐，配音结束延迟可保存。
2. 打开 Script 节点可展开工具；人物、表情、音乐、音效选择器打开时隐藏工具，关闭后只恢复入口。
3. 立绘位置、镜头继承及四种预设可预览；保存后进入正式播放，对应效果与连续对白正常。
4. 绑定当前台词、播放导入语音、等待播放结束并按全局延迟推进；重开工程后绑定可读。
5. Spine 动画列表、切换、入场后的推进和触摸反应正常。

审查另发现已有的重复发布调用路径：MoreEffects 的 EditorSaveService 调用 `Compile()` 后再调用 `Compile(name)`，Voice 的 PublishPlayableAfterBuild 也可在前者后追加 `Compile(name)`。这是此前已有的跨模组行为，本轮没有证据说明它是正式版新增差异，也没有擅自移除保存守卫；可能造成额外编译耗时。后续优化应明确共享保存作用域，并保留配音附属资源的发布观察。正式版的实际保存结果、耗时和官方自动发布行为仍须验收。
