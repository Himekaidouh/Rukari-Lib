## 范围与状态

适配用户最终指定的 `AzureArchive_100_1001` 版 AA 1.0，基线为同日完成侧栏遮挡修复的源码。四包为 RukariLib 0.4.1、更多的画面效果 1.4.0、人物配音支持 1.6.2、更多Spine动画支持 1.6.1。版本号与公共 API 保持兼容；本轮按正式版随包文件重编，不能用文件夹内的旧版本号推断构建来源。

## 原生验收与现有边界

编译和声明检查不能确认官方方法内部行为。本次未启动游戏，也没有修改用户工程或音频。需要在正式版检查：

1. 模组列表加载四包；设置窗口中“模组设置”入口出现且对齐，配音结束延迟可保存。
2. 打开 Script 节点可展开工具；人物、表情、音乐、音效选择器打开时隐藏工具，关闭后只恢复入口。
3. 立绘位置、镜头继承及四种预设可预览；保存后进入正式播放，对应效果与连续对白正常。
4. 绑定当前台词、播放导入语音、等待播放结束并按全局延迟推进；重开工程后绑定可读。
5. Spine 动画列表、切换、入场后的推进和触摸反应正常。

审查另发现已有的重复发布调用路径：MoreEffects 的 EditorSaveService 调用 `Compile()` 后再调用 `Compile(name)`，Voice 的 PublishPlayableAfterBuild 也可在前者后追加 `Compile(name)`。这是此前已有的跨模组行为，本轮没有证据说明它是正式版新增差异，也没有擅自移除保存守卫；可能造成额外编译耗时。后续优化应明确共享保存作用域，并保留配音附属资源的发布观察。正式版的实际保存结果、耗时和官方自动发布行为仍须验收。

## 共享皮肤寿命修复（同日）

用户启动后的首轮日志先确认 Lib 自带 Common 图集校验通过、380 条区域记录可读，并成功创建部分窗口素材；随后创建 `Common_Icon_Gacha`、`Common_Btn_BG` 及蓝色/黄色按钮装饰时，`UnityEngine.Texture.GetDataWidth()` 抛出原生 NullReferenceException。侧栏入口因此显示程序生成的紫色备用图标，部分按钮装饰也丢失。文件没有漏装，切片坐标仍来自配对的随包元数据。

源码缺陷是把仍存在的托管包装器当作有效 Unity 对象，永远复用缓存，读取失败后又永久缓存缺失。日志能证明纹理访问失效；是否由某次 `UnloadUnusedAssets` 直接触发，尚无调用现场证据，不将推测当成已确认的官方行为。

本次修复为共享纹理与 Sprite 明确保留原生资源，并检查缓存两端的有效性；失效时从已校验的 Lib 内存素材重建，暂时失败限频重试。按钮素材恢复时更新原纹理，避免已经复用 Sprite 的控件停留在备用外观。清理逻辑直接释放缓存拥有的两种对象，不再读取已失效 Sprite 的纹理。图集切片缓存同时区分普通与九宫格边界。

四包与四个开发示例重新按最终版当前 interop 构建，0 警告、0 错误，611 项托管检查及四包依赖检查通过。另用实际修改的源码连接假的 Unity API，执行 9 个离线场景、155 项断言，全部通过，覆盖模拟回收、失效重建、延迟恢复、缓存上限与释放；该模拟不执行 Unity，也不验证像素效果。记录位于本地 `src/artifacts/atlas-lifetime-20261001`，不会放进用户 ZIP。

游戏关闭后已同批安装四包：29 个包文件（7 DLL）回读哈希全部匹配，四个已安装插件依赖检查通过，6 个配置文件、2 份日志和 13 项游戏输入保持不变。覆盖前备份共 37 个文件，位于 `src/artifacts/deploy-backups/20261001-214215-188-c84fc51a-atlas-lifetime`，安装收据为 `src/artifacts/atlas-lifetime-20261001/installation.json`。修复候选 ZIP 的 SHA-256 为 `EB7AB7277D71708CBDFD74B7AA28DCCC5F0FF57B294AC32ADD227447071461DB`。没有自动启动游戏。

实现依据：Unity 的 [DontUnloadUnusedAsset](https://docs.unity3d.com/2023.2/Documentation/ScriptReference/HideFlags.DontUnloadUnusedAsset.html) 用于防止未使用资产清理卸载对象；由 Runtime 自己负责显式释放。资源持有与失效防护均作用于 Mod 自建对象，不改变官方资源的回收规则。

待实机检查：首次进入工程、返回目录再进入、反复打开关闭各工具窗口后，侧栏图标、确认/撤销按钮、顶栏与窗口装饰均保持正常。全部功能仍是候选状态。
