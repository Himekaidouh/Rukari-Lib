# Rukari 模组更新日志 · 2026-10-05

本次相较于 2026-10-03 首次正式发布版整理，包含此后完成的兼容修复与功能更新。当前画面效果版本为 1.5.2；人物位移继承重播已分别在 fix6 与 1.0beta 获得用户确认。其他未测路径继续保留原有边界，用户包暂保留候选标记。

| 模组 | 上一发布版 | 本次版本 |
| --- | --- | --- |
| Rukari Lib | 0.4.2 | 0.4.3 |
| 更多的画面效果 | 1.4.1 | 1.5.2 |
| 人物配音支持 | 1.6.4 | 1.6.7 |

## 新增功能

- **立绘 X 轴旋转**：可调整人物前后翻转的角度，与原有 Z 轴平面倾斜分别设置；旋转预设现在可选择 X 或 Y 轴。旧工程的旋转预设仍保持 Y 轴原地转身。
- **独立背景镜头**：镜头操控新增“仅背景”和“整体（背景与人物）”两个范围，分别设置位置、缩放、时长和缓动。同一句可以同时使用两种镜头效果，并分别应用或复位。

## 问题修复

- **人物位移继承**：修复下一句位移动画从默认位置起步的问题，恢复从上一句终点移动到本句目标的效果；修正实时编辑图的节点遍历，并防止继承起点被旧重播状态覆盖。两版已分别确认本次重播问题修复，beta 的重复重播也正常。
- **FL 混合指令重播**：修复启用 FlandreScarletMod 后，尤其是同一张台词卡混用 FL 与 AAVT 指令时，点击绿色重播按钮导致 AAVT 人物效果不执行的问题。该兼容修复已有用户复测反馈。
- **自定义存储路径**：修复更改 AA 存储路径后，立绘效果在编辑器预览正常、正式播放却找不到对应工程的问题。工程识别改为跟随 AA 当前使用的存储位置。
- **旧工程数据残留**：切换工程或存储目录时，使旧索引和待执行效果失效，避免继续使用上一工程的数据；完善效果继承、删除与复位处理，防止已删除的镜头效果从旧保存记录中重新出现。
- **配音版本兼容**：兼容已核对的两版 AA 语音接口，修复部分安装中配音无法播放、同一异常反复写入日志并使日志异常膨胀的问题。
- **配音异常保护**：播放调用发生异常时停止重复尝试并解除模组的配音等待，避免同一错误持续影响对话推进。修正语音加载观察失败时的处理，保留官方正常播放流程。
- **语音导入一致性**：修复导入与音频格式修复同时进行时，新导入记录可能被旧索引覆盖的问题；修复导入取消或失败后，已有语音文件改名未恢复、旧绑定找不到文件的问题。处理限于模组自己的语音存储，不修改用户源音频。
- **工具箱页面保护**：第三方模组工具页发生错误时，仅隔离出错页面，其他页面仍可使用，并释放出错页面占用的焦点与输入。

## 更新与使用说明

- 仍以 **AA 1.0 最新修正版**为主要适配基准。同一套包已完成两版实际 AA 文件的构建和接口核对，不代表兼容所有历史测试版。
- 更新功能模组时，请同时更新 **Rukari Lib 0.4.3**，在官方 Mod 管理中选择新版本并重启 AA。
- 正式播放仍需保存并发布工程；这次更新没有改成官方原生指令注册，也没有完成新的实时保存路线。
- 本次用户包仍为 Lib、更多画面效果、人物配音支持三个独立包。

## 验证范围与已知边界

两版各通过 **850 项自动检查**，最终同一套 DLL 的接口引用核对通过。人物位移继承重播已获两版用户确认；新增 X 轴旋转、双范围镜头、自定义存储路径播放及双版本配音的全部路径仍需分别确认。

本次没有解决所有卡顿，也不保证 FL 与 AAVT 同时修改同一人物的同一属性时可以自动叠加。首次正式播放时，工程索引尚未加载完成导致首条效果遗漏的边界仍需后续处理。最新日志中，官方 `.aap2` 工程的磁盘路径配对仍可能失败；本次编辑器继承修复没有取消配对校验，也没有证明该格式的正式播放已通过。

页码记忆、名称搜索跳转、全局配音音量及播放后等待设置属于既有功能，不列为本次新增。
