# 发布前文件审查

## 结论与状态

本文保留 2026-10-01 初次文件审查及同日侧栏修复的历史记录；这两轮基于 AAfix 4 / Preview10。后续已完成 AA 1.0 fix6 适配与稳定实现的修订，本次正式发布的审查范围见文末，当前版本和用户确认范围见[首次正式发布记录](14_首次正式发布.md)。下面的旧测试数字、版本和安装结论仍只代表各自时点。

## 审查范围

对新仓库最终 425 份跟踪文件读取、分类，核对源码来源清单、实际编译项目、依赖声明、文档链接、图片与元数据、Git 忽略规则及凭据扫描。原开发目录中的历史文件与本地构建输出不是本仓库发布内容，本次未删除它们。

检查范围是现有文件及提交内容，不能仅靠关键词、文件名或哈希证明全部历史开发过程。检查没有发现官方反编译函数源码、dump.cs、DummyDll、游戏程序集、interop DLL、用户工程、用户音频、私钥或访问凭据被提交。自己的 Interop C# 适配代码与官方生成的 interop DLL 是不同的内容。

## 已修正

1. 忽略规则曾把自己的 Interop 源码排除：补齐 24 份 C#，将外部 interop 和 BepInEx 目录规则限定到仓库根。原始来源清单中的文件现均纳入 Git；编译成功不能单独证明上传文件完整。
2. AtlasExportPaths 的开发机 E 盘解包路径与桌面日期目录改为应用目录内 atlas-export。保留原公开签名和 RUKARI_ATLAS_EXPORT 显式配置。共享 UI Runtime 仍只读取自身 DLL 旁的 ui，不使用该兼容辅助类。
3. 图集与字体测试不再默认读取开发机其它游戏或解包文件。可选外部测试夹具通过 RUKARI_TEST_ATLAS_EXPORT、RUKARI_TEST_FONT_FILE 显式指定；默认测试仍有合成输入与随库共享 UI 校验。
4. 当时依赖检查默认范围改为本仓库四个产品，移除不存在的字幕插件定义；初次 FirstRelease 参数仅检查两包，All 对应现有四包。现首发用户范围为 Lib、画面效果与配音三包，正式打包须核验这三个产品的实际依赖；Spine 仍参与四包源码构建核验。
5. 当时首页明确未发布稳定版，素材说明覆盖四张用户提供的图标，不把第三方图像声明为 MIT。

## 保留但需要说明的内容

- 官方 API 的类型名、成员引用、Harmony 补丁与运行观察：属于现有适配技术；依赖内部实现的部分必须随正式版重验。不能称为官方已批准或保证跨版本稳定。
- AAP/AAS 自有读取器与合成格式测试：用于只读识别、索引及测试，未携带真实用户存档；格式研究不同于复制官方函数源码，但这里不替官方解释许可。
- 旧版配音页曾有直接修改工程清单和语音索引的清理操作；用户确认后现已删除按钮、状态、写入实现和清理测试。保留的 VoiceOverrideDiagnostics 仅读取，不创建备份、不删除条目；新测试验证清单、索引及文件集合不变。
- Spine 叠加指令执行服务仍在默认源码中；排除的是实验叠加台 GUI 与试播控制台，而不是整项叠加执行能力。IncludeExperimentalSpineConsole 必须保持 false，仓库没有相应三个文件，开启会构建失败。
- Lib 的字幕模型与测试属于共享公共接口；没有字幕插件发布包，不能因含 Caption 类型就判断打包了半成品字幕模组。
- 测试命令行中的存档检查器与自有工作区证明工具属于开发诊断，不属于用户运行包，也不是反编译器。
- 图片仅为 UI 图集、窗口装饰和四个图标；UI 来源说明已记录，图标原作者与独立授权信息仍待补充。

## 首次正式发布的源码与文件范围（2026-10-03）

本次发布以已安装的 `fix6-voice-navigation-20261003` 稳定快照为来源。净源码树有 433 个文件，构建记录有 418 项输入；包含修复所需的 7 个新增源码/测试文件。根开发分支比稳定快照额外跟踪了 24 个原生指令及实时编辑实验文件，另有 19 个共同文件存在实质实验差异，因此正式源码整体取自稳定快照，不以仅删除实验文件代替来源核验。暂停的原生指令实验和对应 NATIVE 文档不进入正式发布树。

对稳定源码和已跟踪文件进行凭据签名、本机路径、外部二进制、危险清理功能与素材布局检查，未发现私钥、访问凭据、开发者用户目录、固定 E 盘运行依赖、官方反编译函数源码或游戏程序集。净源码树不含 DLL、PDB、真实 AAP/AAS、音频或运行日志。外部游戏、BepInEx 与 interop 程序集仍由本地 `GameRoot` 提供，并设置 `Private=false`。自己的 Interop 适配 C# 属于仓库源码，不能和外部 interop DLL 混为一项。

失效语音清理按钮、清理策略及直接改写官方清单/语音索引的功能没有恢复。`VoiceOverrideDiagnostics` 只读；导入和伴随资源生成只清理自己创建且经过路径包含、重解析点与必要哈希检查的临时文件。

共享 UI 在源码中仅存于 `src/assets/rukari-lib/ui`，共六个文件；运行包只由 Lib 提供一份。两个功能包不重复带 Lib DLL 或图集。三个用户 ZIP 采用明确运行文件清单；本地 `bin`、`obj`、`artifacts`、含本机路径的回执、用户工程、配置及日志不随用户包发布。历史开发文档内的本机安装路径只作追溯资料，不作为用户操作步骤。

本次将 Lib 升至 0.4.2、配音升至 1.6.4、画面效果升至 1.4.1，并同步功能包的 Lib 依赖。新增导航属性保留 `ToolPageSnapshot` 六参数构造与六项解构；发布作用域使用兄弟接口，不改变冻结接口。旧消费者对新 Lib 的兼容性与新消费者的最低版本是两个方向：本批功能包要求 Lib 0.4.2，避免旧 0.4.1 缺少新增类型时仍被版本依赖接受。
