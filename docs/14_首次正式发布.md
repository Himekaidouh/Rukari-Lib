# 首次正式发布（2026-10-03）

本批发布面向 **AzureArchive 1.0 fix6**。用户已确认实际使用中的配音播放、立绘重播，以及配音窗口关闭重开页码保持和名称搜索定位正常，并明确同意将当前稳定实现作为正式版。

## 版本与交付范围

| 产品 | 发布版本 | 首发用户附件 |
| --- | --- | --- |
| Rukari Lib | 0.4.2 | 独立 ZIP；共享契约、Runtime 与唯一一份共享 UI |
| 更多的画面效果 | 1.4.1 | 独立 ZIP；依赖 Lib 0.4.2 |
| 人物配音支持 | 1.6.4 | 独立 ZIP；依赖 Lib 0.4.2 |
| 更多 Spine 动画支持 | 1.6.1 | 保留源码与测试，不进入首发用户附件 |

每个用户 ZIP 仅包含对应模组的 `mods/名称/版本/` 运行目录与简短安装说明。功能包不重复携带 Lib DLL 或共享图集。源码、开发工具、构建回执、配置、用户工程、音频、日志和官方程序集不进入用户附件。

更新时同时安装本批 Lib，并在官方 Mod 管理中选择新版本后重启游戏。具体步骤见[用户指南](users/安装与使用.md)。

## 稳定源码来源

正式源码来自已实际安装的 `fix6-voice-navigation-20261003` 稳定快照，净源码树共 433 个文件，构建记录包含 418 项输入。该快照继承 fix6 适配、编辑器选句捕获、重复发布移除、选槽偏好与配音列表导航修复。

正式发布树基于已有仓库主线整理，整体采用这份稳定源码；暂停的原生指令迁移与实时编辑实验、相应实验文档、隔离探针、游戏程序集和本机构建输出不作为发布输入。第十至十三篇的旧安装版本、哈希和本地证据引用保留为历史记录。

本次升版是对已安装稳定实现的正式版本标记与依赖整理。Lib 0.4.2 为列表导航属性、相关类型及手动发布作用域兄弟接口提供明确版本；配音 1.6.4 与画面效果 1.4.1 的 manifest 和实际 DLL 依赖同步要求 Lib 0.4.2。旧构造、解构与冻结接口保持原签名，避免已编译旧消费者因接口改写失效。

## 变更记录

相对初始 AA 1.0 测试包，本批包含以下已进入稳定实现的修订：

- 适配 AA 1.0 fix6 的实际接口与编译输入。
- 修订编辑器立绘预览的选句捕获时序；同一台词恢复后保留效果窗口的目标槽位，失效授权仍按原规则撤销。
- 移除配音 Mod 在后台普通编译后追加的整份作品发布。手动“保存并发布”继续调用官方保存、编译与命名发布，并由显式作用域覆盖语音伴随资源处理。
- 配音新增全局音量设置，范围 0–100%，默认 50% 保持此前响度。
- 配音列表在同一次游戏会话中按工程及列表来源保存页码、搜索词；名称搜索定位完整列表的匹配页，不自动选择或绑定声音。
- 保持危险失效语音清理功能移除；缺失资源诊断只读。
- 为正式包分配新的 Lib、配音与画面效果版本，同步依赖与安装说明。

具体实现与既有边界见[fix6 适配](10_AA1.0_fix6适配.md)、[立绘预览修复](11_fix6编辑器立绘预览修复.md)、[重复发布与选槽修复](12_fix6重播选槽与卡顿修复.md)和[配音导航修复](13_fix6配音列表页码与搜索定位.md)。

## 验证与用户确认的边界

元数据升版后重新完成四模组与四示例的统一构建，0 警告、0 错误，并通过 **678 项**托管检查：Core 423、Lib 149、Voice 80、Spine 26；两个既有符号链接子夹具因平台权限跳过。真实 DLL 依赖、素材校验与 ZIP 逐项回读均使用本次发布回执独立记录，不沿用旧文件哈希。

用户确认来自实际使用，范围为配音播放、立绘重播、配音窗口关闭重开页码保持及名称搜索定位。工具收据的 `Native=not-run` 仍表示助手没有通过构建工具执行游戏内测试，不把人工反馈写成所有原生路径自动通过。

手动发布后语音伴随资源的完整移交、中文输入法的全部情况、所有镜头/预设/继承组合、场景性能与各类 Spine 资产仍需按具体情况核验。移除额外发布已切断一条明确阻塞路径，不能据此声称所有卡顿消失。其它 AA 版本不在本批兼容范围内。
