# fix6 配音列表页码与搜索定位（2026-10-03）

## 用户行为

人物配音窗口在同一次游戏会话中记住当前页和搜索词。关闭再打开、切到其他工具再回来、切换选中的台词，都不会回到第一页。不同工程、已导入声音列表和文件夹预览分别保留位置；文件夹路径或递归选项变化也使用独立位置。退出游戏后不保存这份浏览状态。

名称搜索保留完整声音列表，优先定位不区分大小写的完整名称，其次定位第一个包含输入名称的条目所在页。支持粘贴名称；回车可再次定位。匹配项用箭头和按钮突出显示，不自动选择、绑定或导入。无匹配时保留原页并显示“未找到”；清空搜索也保留当前页。列表缩短时页码调整到最后一个有效页。

## 实现与兼容性

旧共享抽屉每次选页都调用 `ResetPage()`，把唯一的 `_query` 和 `_listPage` 清零。本轮新增纯托管 `ToolListNavigation`，按工具页 ID 和提供方的列表上下文保留位置；关闭只释放焦点和当前显示引用。重复绘制同一个快照复用导航视图，定位模式不再逐帧复制完整资源列表。

`ToolPageSnapshot.ListNavigation` 是可选的 init 属性，原六参数构造和六项解构保持不变。`ToolListNavigationOptions` 指定 `ContextId` 与 `ToolListSearchMode`。未提供该属性的其他工具页继续使用原来的筛选行为；没有修改冻结接口或新增原生补丁。

配音页用既有的工程捕获入口获取托管工程身份，不用台词 token 作为列表上下文。工程不可用时显示独立空列表并清除待绑定选择，防止把旧工程的声音应用到新工程。后台闲置页没有新增工程轮询或文件读取。
