# 2026.10.06 更新日志

本次更新重点是人物动作编排、动画播放衔接和配音手动跳过。

| 模组 | 版本 |
| --- | --- |
| RukariLib | 0.4.3 |
| 更多的画面效果 | 1.5.5 |
| 人物配音支持 | 1.6.8 |

## 更多的画面效果

### 新增“初始位置 A → 目标位置 B”

立绘操控新增“初始位置 A”“目标位置 B”和“取消指定起点”。可以在同一张台词卡中安排人物从指定起点移动到终点，适合人物入场、镜头切换后的定位和连续动作编排。

- 只设置 A：人物立即定位到 A。
- 同时设置 A、B：人物先定位到 A，再按指定时长与缓动移动到 B。
- 不指定 A：同一人物继承上一句状态；新加入或重新入场的人物使用官方默认槽位。

起点与终点均支持拖拽和 X/Y 按钮调整，可配合时长、缓动、旋转和翻转设置使用。

### 新增动作完成等待

人物位移、旋转、镜头动画，以及设置了次数或时长的预设动作，加入 AA 的动画等待流程。自动播放时，会等待本句有限动作完成再推进，方便用台词卡安排演出节奏。

- 多个动作并行执行时，等待最后完成的动作，不累加各自动画时长。
- 摇摆、转圈、挤压拉伸按次数和频率计算时长，头槌按指定时长处理。
- “直到下一句”的循环效果不造成无限等待。
- 瞬间定位不增加动画等待，切换台词后不继续等待旧动作。

### 修正指令触发与动作衔接

- 改善空台词的指令识别与触发处理。
- 修正同一次推进收到重复回调时，指令可能重复执行、预设动作可能提前停止的处理逻辑。
- 调整快速切换台词时的动作归属和等待清理，使旧台词的等待及时结束。

## 人物配音支持

### 修复配音强制等待问题

修复播放配音时，手动操作也被要求等待语音结束的问题。现在点击对话区域或按 Enter，可沿用 AA 原有的文字显示与推进操作，跳过配音及结束后的额外等待。

配音时长与额外间隔只约束 AUTO；自动播放仍等待语音结束，再按用户设置的间隔推进。

### 优化手动跳过与等待状态

- 调整手动跳过、切换台词时的配音等待清理。
- 将跳过操作限定在对话操作中，点击设置等界面按钮保持正常操作。
- 更新模组设置中的等待说明，明确额外间隔用于 AUTO 播放。

## 版本适配
