## 2. 本轮目标和边界

本轮围绕人物动作与镜头：增加 X 轴旋转、打磨现有预设、增加镜头作用范围，同时补齐直接影响这些功能的预览与合成问题。沿用现有官方编辑/保存 API 和共享指令服务，不直接改写 `.aap`、`.aas` 或官方工程清单。

暂停的官方原生指令注册迁移属于独立研究任务。当前仍包含共享服务净化 `#aavt` 后由托管运行层派发的机制；这次兼容修复没有完成对该机制的整体替换。“效果可预览”和“完全进入官方原生注册、解析、播放链”必须分别验收。

本轮不扩展为三维角色、骨骼级头部动画、战斗系统或完整播放 UI 大修。X/Y 旋转作用于现有立绘平面；侧面厚度、真正的头部动作不会凭旋转产生。

## 3. X 轴旋转

### 用户表现

在立绘操控中增加“X 轴前后倾转”，与现有“Z 轴左右倾斜”明确区分。保留当前 Z 轴控件和旧指令含义。提供数值输入、步进调整、归零、时长与缓动；正负方向先用测试立绘验证，再用统一图示标注。

基础功能支持绝对角度与相对角度。候选版已实现字段 `rotationX` / `drotationX`，稳定旧版 1.4.4 不支持。旧 `rotation` / 相对倾斜字段及 `flipX` 的语义保持不变，未指定 X 时保留原 X 姿态。

旋转预设同时增加“X / Y”轴选择：X 绕立绘横轴连续旋转，Y 保持原地转身。旧工程未指定轴时仍使用 Y。两种旋转均保留圈数、频率、直到下一句结束与曲线设置；新增轴字段同样需要完整解析和规范化，不通过修改旧 Spin 默认行为实现。

### 实现要求

1. 扩展解析、数值校验、规范化文本、目标规划、资源/属性归属及 UI 草稿；不是只在 Transform 上写一个 X 值。
2. 同步覆盖原始姿态、累计姿态、祖先卡继承、未保存覆盖、暂存目标、绿色重播、正式播放、删除和 reset。未控制的轴不得被补成零。
3. 使用统一姿态合成，明确 X/Y/Z 与镜像的顺序；清理时比较旋转方向及拥有的修改，而非仅比较一组易绕回的 Euler 数值。Unity Euler 的应用顺序为 Z→X→Y，现有纯托管姿态比较可以作为基础，见 [Unity 2023.2 旋转文档](https://docs.unity3d.com/cn/2023.2/Manual/QuaternionAndEulerRotationsInUnity.html)。
4. 给预设帧增加 X 倾转通道，保留原构造函数；动作结束、换卡或换人物时只撤销本请求仍拥有的修改，不能清掉后来的官方/FL 动作。连续旋转保留圈数和未绕回的角度轨迹，不能用起终点方向相同推断“无需转动”。
5. 先验证 0°、正负小角度、接近 90°、超过 90°和多圈角度，以及 X+Z、X+Y 转身、镜像组合。侧边变薄、背面是否可见取决于 AA 实际渲染设置，不提前承诺双面材质或透视相机。

本轮沿用现有根支点。脚底固定、胸口支点或自定义支点另列后续功能，需要验证补偿位移与官方动作共存后再开放。

合成承诺限于已经核验并由共享层协调的对象和属性通道。当前清理中的数值/旋转方向相等检查不能证明 FL 5.2 的写入归属；未知同对象同轴组合先采用明确的互斥或拒绝规则，不以最后写入覆盖充当兼容。

## 4. 镜头的两个作用范围

### 用户语义

镜头页增加“整体 / 仅背景”范围选择，分别记住各自的参数。

- **整体**：缩放背景和人物的场景层；台词、按钮、工具窗不随之变大。
- **仅背景**：额外缩放背景层，人物保持其已有大小和位置。
- 两者可以同时使用、分别继承和复位。“仅背景复位”不清掉整体镜头，“整体复位”不清掉仅背景设置；再提供明确的“全部镜头复位”。

旧镜头指令默认等价于“整体”，不改变旧工程画面。“仅背景”使用独立的新作用范围；迁移时不能把旧 zoom 同时灌入两个范围。

设整体缩放为 G、仅背景缩放为 B，缩放倍率相对于各层原始基线：

| G | B | 背景最终倍率 | 人物场景层倍率 | 台词/工具 UI |
| --- | --- | --- | --- | --- |
| 1 | 1.5 | 1.5 | 1 | 保持原样 |
| 1.5 | 1 | 1.5 | 1.5 | 保持原样 |
| 2 | 1.5 | 3 | 2 | 保持原样 |

该表描述缩放。存在平移时，统一以“整体在外、背景局部在内”的顺序合成，同时明确定义坐标单位和支点；不能把两个偏移简单相加，也不能让父子变换重复缩放。

### 当前层级与实现方案

当前 SceneCameraService 并未调整 Unity Camera，而是变换 `UI Root/Back` 及其同级的 `Spine` 场景根。采用两个独立的逻辑状态和**一个最终写入器**：背景写入基线与 B、G 的组合，人物场景根只写入基线与 G 的组合。不得让两个 Tween 分别抢写 Back，也不为实现缩放重挂官方节点。

作用范围要贯穿指令解析、规范化、资源身份、同卡数量限制、编辑 upsert、继承索引、预览覆盖、正式运行及 reset。现有单一 camera 身份需要拆分，允许每卡各有一个整体和背景镜头；同范围的重复规则保持严格。现有视觉指令预算含“一个镜头”，需要同步调整并测试，不能只放开解析。

两个范围均使用包含位置和缩放的内部状态，避免后来添加背景平移时再次破坏格式；本轮首先验收用户要求的缩放。组合后的实际倍率也要校验上下限，不能只校验 B、G 各自数值。普通镜头自定义贝塞尔可作为紧邻的后续项，不混入本轮预设曲线的支持声明。

**必须先确认背景边界**：普通背景、背景特效、动态大厅等资源可能不全在 Back。实际位于人物/Spine 层的内容不会因 Back 缩放自动跟随。以运行层级和对象归属确定可覆盖的内容，再决定是否需要专门适配；不按资产名称猜测，也不宣称全部粒子天然支持。

### 新发现的预览删除条件路径（计划编号 C13）

源码核对发现：编辑覆盖已声明场景具有权威性，但 camera 被删掉时，`TryGetOverlayDirective` 返回 false；镜头继承消费者仅在返回 true 时检查权威标记，随后可能回退到旧保存索引，重新取回已经删除的祖先镜头。

这是**源码确认的条件路径，尚未实机复现**，不是此前审查 C01–C12 中已经完成的修复。应将查询结果明确分为“未覆盖 / 有命令 / 权威空值或删除”，权威删除禁止回退。先加单范围回归，再扩展到两个作用范围。

## 5. 现有预设的完善程度与小窗

以补足官方已有演出为定位，目前四类预设已经形成足够清楚的功能范围，不需要按数量扩充。用户已经指出呼吸、抖动与跳跃的重复，整张立绘点头也不符合需求；这些项目不进入本轮交付。

| 已有预设 | 补足的演出 | 本轮处理 |
| --- | --- | --- |
| 左右倾斜摇摆 | 持续或有限次数的激动晃身，调整倾斜幅度、频率及曲线 | 保留，核验循环停止与归位 |
| Y 轴原地转身 | 可调圈数/频率的原地旋转，或持续到下一句 | 保留旧 Y 行为，增加 X/Y 轴选择 |
| 人物头槌 | 可调后仰/前冲角度及速度的蓄力、撞击、回位 | 保留三阶段动作，核验分段曲线和回位 |
| 挤压与拉伸 | 竖向/横向交替的软弹变形 | 保留面积补偿和幅度/频率设置，核验结束恢复 |

动作种类和参数表达较完整，不等于所有运行边界已经验收。接下来主要补齐暂停/快进、换卡、换人、清理归属、未保存预览和 FL 共存。暂不为这些已覆盖动作新增位置动画通道。强弱风格可通过现有参数获得，不把改变默认参数包装成新的运行机制。

### 动作模型

- 保留一个槽位一种活动预设的第一版规则，不开放多个独立预设无序叠加。
- 次数、周期频率和单次总时长按动作类型呈现；继续支持可循环动作直到下一段对话，换卡后归位。对头槌这类单次动作，不显示没有语义的循环频率。
- 给新增 X 旋转通道同步补齐基线捕获、逐帧合成、归属验证和结束清理；既有预设也核验相同路径，避免清理时写回过期姿态。
- 优先明确暂停、快进和跳卡的时钟语义。若尚未取得可靠的故事时钟，必须记录支持范围，不能靠任意延时推断暂停状态。
- 曲线继续使用公共的贝塞尔参数小窗。第一版控制点保持在 0–1 内；回弹、蓄力、冲击由实际运动轨迹与分段动作表达，不通过放开非法控制点制造越界。

### 窗口布局

维持已有“预设效果”入口，旋转的轴选择放在该动作的参数小窗，不新增平级动作按钮。

当前动作列表维持四项，保留标题和底部余量；选中动作后打开参数小窗，再从参数窗进入曲线设置。滚动列表和可扩展目录待出现确有用途的新动作时再做，不作为当前四项列表的强制改造。

小窗共用 Lib 的主题、尺寸约束、输入占用与生命周期服务。官方人物/差分/声音选择窗口打开时，侧边栏、列表和参数窗一起避让。当前预设会在 OnHidden 时丢弃草稿，临时遮挡保留需要另行实现：仅在选句、修订和内容证明仍一致时恢复选槽与参数，并重新核验写入权限；选句变化则作废，不能复用旧 selection key。手动关闭按明确的取消/保留产品规则处理，不与临时遮挡混同。第三方自建窗口的避让需共享遮挡注册，不能只依赖官方 WindowManager。

当前枚举、解析器及运行层没有公开的第三方预设注册服务；对外开放动作还需注册/注销、参数校验、通道归属及运行释放契约，单列后续接口设计，不能把内部新增一项称为公共插件接口。

## 7. 实施阶段与交付

### A：收紧基础行为

完成 C05、C13，并处理 C04 的冷首卡路径；为 C09 确定单槽变换所有权、归位规则和时钟支持范围。记录 C12 的性能基线，不通过扩充动作数量回避这些问题。

交付：对应纯托管回归、支持范围说明、未保存镜头删除不复活、冷首卡不漏执行且迟到任务不串卡。

### B：X 轴与姿态链
