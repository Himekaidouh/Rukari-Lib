# 有限动作与官方播放时间轴（1.5.5 候选）

## 用户行为

不指定初始位置 A 时，沿用上一句同一人物的状态；新加入或重新入场的人物使用官方槽位。显式 A 会在这一句开始时立即定位，然后执行 A→B。只设 A 是瞬时设置，不增加动画时长。

有限的位移、旋转、镜头动画和预设动作加入 AA 的动画完成边界。多个动作并行时等待最晚完成的那个，而不是把时长相加。摇摆、转圈、挤压拉伸按“次数÷频率”计时；头槌使用指定时长；“直到下一句”的循环不阻止进入下一句。

这层没有往额外指令框或 AAP/AAS 写入 `#wait`。用户不必手动补等待指令。官方动作、文字和语音仍由原本的 AA / 对应 Mod 管理；语音手动跳过修订保留，不能把视觉动画的等待相加成第二份语音等待。

## 接入方法

1. 在真实的 `Test.AdvanceScenario` 观察窗口内，读取 `Utils.ScenarioUtil.ParseScript` 实际接收的 `IScenarioScriptExcel.ScriptKr` 和 `Test.cur`。即使字符串是空，也是一份输入；没有输入则没有授权。普通日志只作旧路径兜底。
2. 在该次解析返回的 `ScriptInfo.scenarioAnimations` 中加入一个 **官方 `ScenarioAnimation.WaitAnimation` 实例**。先给实际派发留出有限的启动窗口。
3. 现有编辑器租约、保存索引和窗口去重仍负责授权。只有真正成功执行的动作报告完成期限；时间从实际执行开始算，不从保存或索引加载开始算。
4. 有限动作执行完毕后封存这个期限。将本次 WaitAnimation 自己的原生 `WaitTask` 重新设为实际期限加有限余量；不重复调用 `Start`，不改写 AA 的动画计数，也不替换播放器的推进协程。
5. 在 LateUpdate 中观察预设、镜头状态和人物目标。先确认仍是同一播放器、模式、行、存储上下文和当前动画列表里的同一个原生对象，再结束自己的等待。由 AA 的完成回调处理推进；不主动调用 `AdvanceScenario`。

人物的位置和旋转分别跟踪最后一次写入的目标，另一通道的目标保留。读取目标只发生在应当完成时，而不是整个动作期间每帧遍历。人物被移除后不再阻塞这一句。

## 启动、取消与失败

- 首次正式播放索引尚未就绪时，最多保留一个拥有当前原生等待的真实窗口。索引准备好且同一行仍有效才重新观察它。已跳到其它行、中止的调用或旧存储上下文不补发。
- 已知不含本 Mod 指令的台词不加等待；只有首次索引未知的台词会临时等待索引结果。
- 指令验证失败、租约失效、重复窗口和派发失败不延长等待。
- 启动等待最多 10 秒。已启动的动作在预计截止时间后仍未完成时有 3 秒诊断余量；失败会记录超时并释放，不无限卡住播放。
- 手动取消或切换台词后停止追踪旧的等待，不把它搬到新的台词。
- 原生对象不跨帧持有包装器，只保留数值指针并在当前动画列表重新取得。没有新增自定义 IL2CPP 动画类。

配置：`[PlayerCommandObservation] ActionTimelineEnabled = true`，改动后重启。设为 `false` 可恢复之前的动作等待行为，真实解析输入观察仍保留。

## 空台词的适用边界

**动画等待和保存映射是两个问题。** 本候选改善已获得有效对应关系的空台词：真实解析输入可以为空，瞬时设置先派发，有限动画不会因下一句太快开始而立即被清理。

整个 Script 节点完全没有文字时，保存的 AAP 场景与 AAS 播放记录仍需要官方编译输出的可靠对应关系。当前安全捕获未覆盖所有生产编译路径；若日志是 `compile-mapping-capture: no observed script emissions; proof omitted`，本候选没有完成这类全空节点的修复。不能把等待功能或普通空卡片测试通过当成这项已经通过，更不能凭行号或源文件排列猜测绑定。

## 原生验收（fix6 与 1.0beta 都需要）

使用三号槽位的同一人物，同一 Script 节点内保留一个有文字的卡片作为当前保存映射锚点。前面的空卡片依次测试：

```text
#aavt;char;3;set;startX=-600;startY=0;duration=0;easing=linear
```

```text
#aavt;char;3;set;x=600;y=0;duration=2000;easing=easeInOut
```

第二句不显式设 A，应从上一句终点开始移动，有限移动应完成后再自动推进。

分别增加有限摇摆和循环摇摆：

```text
#aavt;fx;3;sway;amplitude=25;frequency=2;cycles=4;direction=right
```

```text
#aavt;fx;3;sway;amplitude=25;frequency=2;cycles=0;direction=right
```

有限摇摆约 2 秒后完成；循环摇摆不应造成永久等待。再测试并行的移动与镜头、绿色重播多次、手动跳过、开头直接 AUTO、语音+效果，以及 FL+AAVT 混合重播。整段全空节点单独测、单独记录结果。

日志中应能看到 `action-timeline: armed` 和对应的 `released`，而不是不断追加相同等待。构建和离线测试能验证时间计算、窗口输入和失败边界，无法代替原生回调、手动取消和动画观感验收。
